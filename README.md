# My Life Dashboard

Een persoonlijke, lokale web-app voor school, planning, taken, focus en flight sim.

## Wat zit erin?
- Dashboard met vandaag, open taken, weekvoortgang en laatste vlucht
- Taken met deadline, prioriteit, zoeken en filters
- Kalender/planning
- School Hub met vakken en schoolwerk
- Flight Log met afstand, tijd en ratings
- Focus timer (25 / 50 / 5 minuten)
- Statistieken
- Donker/licht thema
- Lokale opslag via `localStorage`
- Responsive ontwerp voor desktop en mobiel

## Starten
Open `index.html` in je browser. Er is geen backend nodig.

## GitHub Pages
Ga in GitHub naar **Settings → Pages** en kies **Deploy from a branch**, branch **main**, folder **/(root)**.

Alle persoonlijke data blijft standaard in de browser waarin je de app gebruikt.
